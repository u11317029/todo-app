# 第 01 關：開天闢地

> 對應投影片：git init、三個區域、.gitignore

## 情境

你剛下載了一個待辦清單網頁，它還只是一個普通資料夾。專案裡需要一組 API 金鑰，但金鑰絕對不能存進 Git。

## 任務

把這個資料夾變成 Git 儲存庫，並做出第一個 commit，而且 `.env` 不能被存進去。

## 步驟

1. 在 GitHub 上打開練習專案的頁面，點綠色的 **Code** 按鈕，選 **Download ZIP**，解壓縮。
2. 進到解壓縮出來的資料夾，按右鍵 **Open Git Bash here**。
3. 雙擊 `index.html`，看看網頁長什麼樣子。發現標題的錯字了嗎？先別管它，之後的關卡會處理。
4. 建立你的金鑰檔，並填入一組假的金鑰：

   ```bash
   cp .env.example .env
   ```

   用編輯器打開 `.env`，在 `OPENAI_API_KEY=` 後面隨便填一串字，例如 `sk-practice-123`。

5. 開天闢地：

   ```bash
   git init
   git status
   ```

   注意看 `git status` 的輸出：`.env` 有出現在清單裡嗎？

6. 把所有檔案放進暫存區，再存成第一個 commit：

   ```bash
   git add .
   git commit -m "建立待辦清單專案"
   ```

<details>
<summary>卡住了？看提示</summary>

- `.env` 沒有出現在 `git status` 裡，是因為 `.gitignore` 第一行就寫了 `.env*`。打開 `.gitignore` 看看還忽略了哪些東西。
- `uploads/` 資料夾裡也有一份 `.gitignore`，它用 `*` 忽略所有上傳的檔案，再用 `!.gitignore` 把自己留下來。
- 如果分支名稱不是 main，執行 `git branch -M main`。

</details>
