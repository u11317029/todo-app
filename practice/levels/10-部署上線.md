# 第 10 關：部署上線

> 對應投影片：GitHub Actions、用 Actions 做 CI/CD

## 情境

你的待辦清單網頁只有你自己能在電腦上打開。用 GitHub Pages，可以免費把它變成一個任何人都能造訪的網站。

## 任務

開啟 GitHub Pages，讓 Actions 自動部署你的網站。

## 步驟

1. 打開 repo 裡的 `.github/workflows/pages.yml` 看看。找得到 `on`、`jobs`、`steps` 這三個部分嗎？它的意思是：「只要 main 有新的 commit，就自動部署網站」。
2. 到 GitHub repo 的 **Settings → Pages**。
3. **Build and deployment** 底下的 **Source**，選 **GitHub Actions**。
4. 到 **Actions** 分頁，點左側的 **Deploy to GitHub Pages**，再點右側的 **Run workflow** → **Run workflow**。
5. 等它變成綠色 ✓，大約一兩分鐘。點進去會看到你的網站網址：

   ```
   https://你的帳號.github.io/todo-app/
   ```

6. 打開網址，你的待辦清單上線了！

<details>
<summary>卡住了？看提示</summary>

- 第 09 關 push 之後出現的紅色 ✗，是因為當時還沒開啟 Pages。現在開好之後重新執行就會成功。
- 網址打開是 404？第一次部署有時要多等一兩分鐘。
- 另一個 workflow「CI」也會在每次 push 時執行。打開 `scripts/ci-check.sh` 看看它檢查了什麼。

</details>
