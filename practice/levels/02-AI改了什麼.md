# 第 02 關：AI 改了什麼？

> 對應投影片：git status、git diff、如何寫好一個 commit

## 情境

你請 AI 幫網頁換個配色。它說改好了，但它到底改了哪裡？

## 開始

```bash
bash practice/start.sh 2
```

## 任務

先看清楚 AI 改了什麼，確認沒問題後，用一則清楚的訊息存成 commit。

## 步驟

1. 重新整理網頁，看看顏色有沒有變。
2. 看哪些檔案被改了：

   ```bash
   git status
   ```

3. 看改了哪幾行：

   ```bash
   git diff
   ```

   `-` 開頭是刪掉的行，`+` 開頭是新增的行。

4. 確認沒問題，存檔：

   ```bash
   git add style.css
   git commit -m "網頁改成青綠色主題"
   ```

<details>
<summary>卡住了？看提示</summary>

- `git diff` 的畫面太長時，可以用方向鍵捲動，按 `q` 離開。
- 訊息太模糊被檢查擋下時，用 `git commit --amend -m "新的訊息"` 修改最後一個 commit 的訊息。

</details>

## 對 AI 說

> 「給我看這次改了哪些地方。」

## 檢查

```bash
bash practice/check.sh 2
```
