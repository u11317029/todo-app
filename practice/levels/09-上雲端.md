# 第 09 關：上雲端

> 對應投影片：remote、建立帳號與 2FA、開 repo、驗證

## 情境

到目前為止，所有歷史都只存在你的電腦上。電腦壞了，一切就沒了。現在把它放上 GitHub。

## 事前準備

- 有一個 GitHub 帳號，並且**已經開啟 2FA**（Settings → Password and authentication）。

## 任務

在 GitHub 建立一個空的 repo，把本機的專案推上去。

## 步驟

1. 在 GitHub 右上角點 **＋** → **New repository**。
2. Repository name 填 `todo-app`，選 **Public**。
   > 第 12 關的分支保護，在免費方案只能用在 public repo。
3. **不要勾選** Add a README、.gitignore、license，建立一個空的 repo。
4. 建好之後，GitHub 頁面會顯示指令。在 Git Bash 裡執行（把網址換成你的）：

   ```bash
   git remote add origin https://github.com/你的帳號/todo-app.git
   git push -u origin main
   ```

5. 第一次 push 時，會跳出瀏覽器視窗要你登入 GitHub。登入並通過 2FA 後，push 就會完成。
6. 重新整理 GitHub 頁面，你的程式碼和所有 commit 都上去了。點 **commits** 看看，前面每一關的歷史都在。

<details>
<summary>卡住了？看提示</summary>

- 沒有跳出瀏覽器？可以安裝 [GitHub CLI](https://cli.github.com/)，執行 `gh auth login`，選 GitHub.com → HTTPS → 用瀏覽器登入。
- 出現 `remote origin already exists`：用 `git remote set-url origin 正確網址` 修改。
- 推上去之後，Actions 分頁可能會出現一個紅色 ✗ 的「Deploy to GitHub Pages」。這是正常的，下一關會處理。
