# 第 04 關：改壞了！

> 對應投影片：後悔藥（git restore）

## 情境

AI 說它「重構了一下程式碼」。結果網頁歪了一邊，而且連新增待辦事項都不行了。還好你還沒 commit。

## 開始

```bash
bash practice/start.sh 4
```

## 任務

把 AI 這次的修改全部丟掉，讓網頁回到上一個 commit 的樣子。

## 步驟

1. 重新整理網頁，試著新增一個待辦事項。
2. 用 `git diff` 找出 AI 改了哪裡。你能看出是哪一行讓程式壞掉的嗎？
3. 把修改丟掉：

   ```bash
   git restore app.js style.css
   ```

   也可以一次全部還原：`git restore .`

4. 重新整理網頁，確認恢復正常。

> ⚠️ 被 `git restore` 丟掉的修改救不回來，所以執行前一定要先用 `git diff` 確認。

## 對 AI 說

> 「把這次的修改全部還原，回到上一個 commit。」

## 檢查

```bash
bash practice/check.sh 4
```
