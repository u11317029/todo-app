# 第 11 關：第一個 Pull Request

> 對應投影片：GitHub Flow、一個人開發的 PR

## 情境

你想加上深色模式。照 GitHub Flow：開分支、開 PR、等 CI 通過、審查後再合併。

## 任務

在 `feature-dark-mode` 分支上加入深色模式，用 Pull Request 合併進 main，並看它自動部署上線。

## 步驟

1. 先拿到最新的 main，再開分支：

   ```bash
   git switch main
   git pull
   git switch -c feature-dark-mode
   ```

2. 讓 AI 加上深色模式：

   ```bash
   bash practice/start.sh 11
   ```

3. commit 並推上 GitHub：

   ```bash
   git add style.css
   git commit -m "加入深色模式"
   git push -u origin feature-dark-mode
   ```

4. 到 GitHub repo 頁面，會看到黃色提示框，點 **Compare & pull request**。
   - 也可以用指令：`gh pr create --fill`
5. 寫好 PR 的標題和描述：**做了什麼、為什麼、怎麼測試**。
6. 等下方的 **CI** 檢查變成綠色 ✓。
7. 點 **Files changed**，用審查別人程式碼的心態看一遍。
8. 回到 **Conversation**，點 **Merge pull request** 旁邊的箭頭，選 **Squash and merge**，再按確認。
9. 點 **Delete branch** 刪掉 GitHub 上的分支。
10. 回到本機，更新 main 並刪掉本機分支：

    ```bash
    git switch main
    git pull
    git branch -D feature-dark-mode
    ```

11. 等一兩分鐘，打開你的網站，把電腦切換成深色模式看看！

<details>
<summary>卡住了？看提示</summary>

- 第 10 步要用大寫的 `-D`：squash 合併會產生一個全新的 commit，Git 認不出這個分支已經合併過，所以小寫的 `-d` 會拒絕刪除。
- 想看合併後的部署進度：到 Actions 分頁，或執行 `gh run list`。

</details>
