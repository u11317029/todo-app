# 第 07 關：平行世界

> 對應投影片：branch、分叉之後、merge

## 情境

你想請 AI 加一個搜尋功能，但不確定它會不會改壞東西。這時就開一個分支，讓它在平行世界裡試。

## 任務

在 `feature-search` 分支上加入搜尋功能，切回 main 觀察差別，最後合併回 main。

## 步驟

1. 開分支並切過去：

   ```bash
   git switch -c feature-search
   ```

2. 讓 AI 加上搜尋功能：

   ```bash
   bash practice/start.sh 7
   ```

3. 重新整理網頁，試試搜尋框。沒問題就 commit：

   ```bash
   git add .
   git commit -m "加入搜尋功能"
   ```

4. 切回 main，再重新整理網頁：

   ```bash
   git switch main
   ```

   搜尋框不見了！它還在 `feature-search` 這個平行世界裡。

5. 搜尋功能確定沒問題，把它合併進 main，然後刪掉用完的分支：

   ```bash
   git merge feature-search
   git branch -d feature-search
   ```
