# 第 03 關：一次只做一件事

> 對應投影片：如何寫好一個 commit、commit 訊息的結構

## 情境

AI 很熱心，一口氣幫你做了三件事：修好標題錯字、加上按 Esc 清空輸入框、把清單間距拉開。如果全部塞進同一個 commit，之後其中一件出問題，就沒辦法只撤回那一件。

## 開始

```bash
bash practice/start.sh 3
```

## 任務

把三件事拆成**三個 commit**，每個 commit 只改一個檔案，訊息要寫清楚做了什麼。

## 步驟

1. 用 `git status` 看看改了哪些檔案，再用 `git diff 檔名` 一個一個看。
2. 一次只 add 一個檔案，然後 commit：

   ```bash
   git add index.html
   git commit -m "修正標題錯字"
   ```

3. 對另外兩個檔案重複一次。
4. 用 `git log --oneline` 看看你的三個 commit。

<details>
<summary>卡住了？看提示</summary>

- 不小心把兩個檔案放進同一個 commit？執行 `git reset --soft HEAD~1`，可以撤回最後一個 commit，修改會留在暫存區，再用 `git restore --staged 檔名` 拿出來重新分。
- 想整關重來：執行 `git log --oneline` 找到開始前的 commit，用 `git reset --hard 編號`，再重新執行 `bash practice/start.sh 3`。

</details>
