# 第 08 關：合併衝突

> 對應投影片：衝突：兩邊改到同一行

## 情境

AI 在 `feature-color` 分支上把標題改成紫色，同事小林在 main 上把標題改成深綠色。兩邊改到同一行，Git 不知道該聽誰的。

## 開始

```bash
bash practice/start.sh 8
```

## 任務

合併 `feature-color`，解決衝突，完成合併 commit。

## 步驟

1. 合併：

   ```bash
   git merge feature-color
   ```

   Git 會回報 `CONFLICT`，這是正常的。

2. 用編輯器打開 `style.css`，找到這一段：

   ```
   <<<<<<< HEAD
   h1 { color: darkgreen; }
   =======
   h1 { color: purple; }
   >>>>>>> feature-color
   ```

3. 決定要哪個顏色，只留下那一行，並把 `<<<<<<<`、`=======`、`>>>>>>>` 三種標記全部刪掉。
4. 告訴 Git 衝突解決了，再完成合併：

   ```bash
   git add style.css
   git commit --no-edit
   ```

5. 用 `git log --oneline --graph` 看看兩條線怎麼合在一起。

<details>
<summary>卡住了？看提示</summary>

- VS Code 會在衝突上方顯示「Accept Current Change」「Accept Incoming Change」等按鈕，點一下就能選擇。
- 想放棄這次合併，回到合併前：`git merge --abort`。
- 合併完成後，可以用 `git branch -d feature-color` 刪掉分支。

</details>
