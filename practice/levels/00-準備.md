# 第 00 關：準備工具

開始練習前，先把工具準備好。這一關只需要做一次。

## 1. 安裝 Git

- **Windows**：到 [git-scm.com](https://git-scm.com/) 下載 Git for Windows，安裝時一路按 Next 即可。它會一起裝好 **Git Bash**，後面所有指令都在 Git Bash 裡執行。
- **Mac**：打開「終端機」，輸入 `git --version`。如果還沒安裝，系統會提示你安裝。

## 2. 學會打開 Git Bash

在專案資料夾的空白處按右鍵，選 **Open Git Bash here**。

Windows 11 的右鍵選單比較精簡，要先點「**顯示其他選項**」才看得到。

> 💡 在 Git Bash 裡，複製是 `Ctrl + Insert`，貼上是 `Shift + Insert`，也可以直接按滑鼠右鍵選擇。

## 3. 告訴 Git 你是誰

每個 commit 都會記錄作者，所以第一次使用要設定名字和信箱。之後在 GitHub 上會用到，建議填你註冊 GitHub 的信箱：

```bash
git config --global user.name "你的名字"
git config --global user.email "you@example.com"
git config --global init.defaultBranch main
```

## 4. 推薦：安裝 VS Code

[VS Code](https://code.visualstudio.com/) 是免費的程式編輯器，打開檔案、看 diff、解衝突都很方便。也可以用你習慣的 AI 編輯器，例如 Cursor。

## 檢查

下載練習專案後，在專案資料夾裡打開 Git Bash，執行：

```bash
bash practice/check.sh 0
```

看到「過關！」就可以開始第 01 關。
