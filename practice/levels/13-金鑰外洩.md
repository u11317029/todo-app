# 第 13 關（選做）：在 commit 之前擋下金鑰

> 對應投影片：pre-commit、不小心把金鑰推上 GitHub？

## 情境

AI 幫你產生了一把部署用的金鑰 `deploy-key.pem`，還叫你一起 commit。一旦推上 GitHub，這把金鑰就外洩了。這次讓 pre-commit 在 commit 之前就擋下它。

## 事前準備

pre-commit 需要 Python。

- **Windows**：到 [python.org](https://www.python.org/) 下載安裝，安裝時記得勾選 **Add python.exe to PATH**。
- 然後安裝 pre-commit（只要做一次，之後每個專案都能用）：

  ```bash
  pip install pre-commit
  ```

  如果已經裝了 pipx，用 `pipx install pre-commit` 更好，它會把工具裝在獨立的環境裡，不會和其他專案打架。

## 開始

```bash
bash practice/start.sh 13
```

## 任務

啟用 pre-commit，親眼看到金鑰被擋下，再用 `.gitignore` 確保它以後也不會被 add。

## 步驟

1. 打開 `.pre-commit-config.yaml` 看看，最後一項 `detect-private-key` 就是偵測私鑰的檢查。
2. 在這個 repo 啟用 pre-commit：

   ```bash
   pre-commit install
   ```

3. 照 AI 說的，把金鑰 add 並 commit：

   ```bash
   git add deploy-key.pem
   git commit -m "加入部署金鑰"
   ```

   第一次執行會花一點時間下載檢查工具。接著你會看到 `detect private key ... Failed`，commit 被擋下來了！

4. 把金鑰移出暫存區，並讓 Git 以後都忽略 `.pem` 檔：

   ```bash
   git restore --staged deploy-key.pem
   echo "*.pem" >> .gitignore
   git add .gitignore
   git commit -m "忽略金鑰檔"
   ```

<details>
<summary>卡住了？看提示</summary>

- 找不到 `pip`？試試 `py -m pip install pre-commit`，之後用 `py -m pre_commit install`。
- 其他檢查也可能自動修改檔案，例如刪掉行尾空白。這時 commit 會失敗，重新 `git add` 被修改的檔案再 commit 一次就好。
- 真實情況下，如果金鑰已經推上 GitHub，第一件事是**到服務後台作廢它**，再處理其他事。

</details>
